## 判定阈值（《采购与付款内控制度》）

- 三单容差：数量差值 <= 2% 且超开金额 <= 1,000 元 -> 低风险
- 少货多付高风险：数量差值 > 10%，或超开金额 > 10,000 元，且无有效审批
- 少货多付中风险：2% < 数量差值 <= 10%，或 1,000 < 超开金额 <= 10,000 元，且无完整审批
- 大额采购审批红线：单笔 PO 价税合计 >= 500,000 元
- 拆单观察窗口：同一供应商 5 日内多笔订单
