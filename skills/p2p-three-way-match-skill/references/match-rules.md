# 三单匹配计算口径

## 数量与金额

- 数量差 = 发票数量 - 入库数量
- 数量差% = 数量差 / 入库数量 × 100
- 入库数量为 0：无法匹配，证据不足
- 超开金额 = 发票价税合计 - 入库数量 × 订单单价 × (1 + 税率)
- 税率优先用发票 `taxRate`，缺省则用 PO `taxRate`

## ③ 少货多付 / 数量金额异常

- 高风险：数量差% > 10，或超开金额 > 10,000 元，且无有效审批
- 中风险：2 < 数量差% ≤ 10，或 1,000 < 超开金额 ≤ 10,000，且无完整审批
- 低风险：完全一致，或数量差% ≤ 2 且超开金额 ≤ 1,000；或仅开票/入库时间差且数量金额一致；或有完整补货/分批/调价审批（COMPLETED）
- 证据不足：缺 GR 或缺 Invoice

两个条件取更高等级（例如数量差 4% 但超开 12,000 元 → 高风险）。

## ⑤ 重复发票

- 高风险：相同 `invoiceCode + invoiceNo` 出现两次以上，且被多次关联报销/付款
- 中风险：发票号不同，但供应商、金额、开票日期高度一致
- 低风险：号码唯一

全量发票只看 summary / artifact，禁止把全部发票正文塞进证据。

## ⑥ 税率异常

- 服务类默认 6%；原材料 / 外协 / 办公采购 13%
- 税额差 = 未税金额 × (类别默认税率 − 发票税率)；正数少计税，负数多计税；分级用绝对值
- PO 与发票税率相同不是低风险充分条件，还须对照 `category`
- 高风险：无审批，且（发票 ≠ PO 且税额增加，或与 category 默认税率不一致的孤立/少数异常且 |税额差| > 10,000）
- 中风险：变更审批 COMPLETED 但 `category` 未同步；或无审批且 1,000 < |税额差| ≤ 10,000
- 低风险：发票、PO、类别默认三者一致；或 |税额差| ≤ 1,000；或审批闭环且后续开票符合新范围
- 证据不足：缺 category 或税率字段。已确认错税率不得降为证据不足
- 没有 `VENDOR_PROFILE_CHANGE` 这种审批类型；用 `approval-query(keyword=税率|经营范围)`

## 消解

`approval-query(businessId=PO或供应商ID, keyword=补货|分批|价格|税率|经营范围)`。  
未查询不得写无审批。查询 0 条写「ERP 未检索到…」。
