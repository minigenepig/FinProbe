# 拆单判定辅助

## 红线与窗口

- 大额采购红线：单笔 `totalWithTax` >= 500,000 元，须部门经理 → 采购总监 → 财务总监加签
- 观察窗口：同一供应商 5 日内
- 接近红线：450,000 <= 单笔 < 500,000
- 合计越线：sum(totalWithTax) >= 500,000
- 物料一致：聚类内 `itemCode` 集合大小为 1

## 分级

- 高风险：5 日内多笔均低于红线且接近红线，物料高度一致，无独立项目说明
- 中风险：相近时间多笔，但审批注明不同部门/项目（厂务部/IT部/行政部等）
- 低风险：间隔超过 5 日，或无故意拆单特征
- 单笔已 >= 500,000 且大额审批 COMPLETED：不按拆单处理

## 消解

独立项目：审批 `submitComment` / `nodes.comment` 含项目名称或需求部门。  
本环境 `receivedBy` 多为 EMP-3392、仓库多为 WH-01-A，不能单独作为高风险充分条件。
